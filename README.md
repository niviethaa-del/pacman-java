# Pac-Man Game in Java

## About
This project is a Pac-Man game developed using Java. It includes Pac-Man character sprites, ghosts, food, and wall graphics.

## Features
- Pac-Man character graphics
- Ghost characters
- Food and wall images
- Java-based game project

## Technologies Used
- Java
- PNG image assets

## Project Files
- `App.java` — Main application entry point (if configured as such)
- `PacMan.java` — Pac-Man game class
- `blueGhost.png` — Blue ghost sprite
- `orangeGhost.png` — Orange ghost sprite
- `pinkGhost.png` — Pink ghost sprite
- `redGhost.png` — Red ghost sprite
- `pacmanUp.png` — Pac-Man facing up
- `pacmanDown.png` — Pac-Man facing down
- `pacmanLeft.png` — Pac-Man facing left
- `pacmanRight.png` — Pac-Man facing right
- `wall.png` — Wall graphic
- `powerFood.png` — Power food graphic
- `cherry.png` and `cherry2.png` — Cherry graphics

## How to Run
1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in a Java IDE such as IntelliJ IDEA, Eclipse, or VS Code.
4. Configure the project and run the main application class.

The exact compilation and execution commands depend on the project's Java setup.
